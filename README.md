# Pokédex · Modo estudio

Guía para preparar la presentación del proyecto del Módulo 3 ([Pokédex](https://github.com/naaria/pokedex)).

🔗 **Ver la guía:** https://naaria.github.io/pokedex-estudio/

Incluye:

- Guion de la demo de 10 minutos y la rúbrica.
- Las 2 historias de usuario del proyecto con sus criterios de aceptación.
- Diagramas del flujo de datos y del manejo de errores.
- Los conceptos de los labs 09–12.
- Todo `app.js` explicado línea por línea.
- Preguntas probables, un quiz y una chuleta final.

Es una sola página HTML responsive (`index.html`). El progreso de estudio se guarda en el navegador con `localStorage`.
